# Live Architect API (fase 3)

Hier komt in fase 3 het Node-servicetje dat op Railway draait:

- Railway Postgres als database (ontwerpen, opmerkingen, e-mailadressen).
- Endpoints: ontwerp opslaan/laden via een deelbaar token, opmerkingen toevoegen/afvinken, e-mail vangen bij opslaan.
- De browser praat alleen met deze API, nooit rechtstreeks met de database.
- Fase 4: renderproxy-endpoint voor AI-beelden (sleutels blijven hier).
- Fase 5: websockets voor de realtime sessiemodus.
